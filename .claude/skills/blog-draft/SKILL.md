# blog-draft スキル

## 概要

箇条書きの下書きをもとに、satbunch.comのブログ記事を作成する。
記事の種類によって文体が異なるため、必ず書く前に確認を取る。

## 文体ルール

- **テックブログ**: ですます調（丁寧な解説文）
- **日記・雑記**: だ・である調。「〜だと思う」「〜なんじゃないか」「〜だろうか」などの個人的な語り口を使う

## 手順

### 1. 下書きを受け取る

ユーザーから箇条書きのメモや下書きを受け取る。すでにコンテキストにある場合はそれを使う。

### 2. 書く前に以下を確認する（まとめて1回で聞く）

```
以下を教えてください：

1. **記事の種類**: テックブログ（技術的な解説）ですか？それとも日記・雑記（考えや体験の記録）ですか？
2. **記事のファイル名**: `src/content/posts/` に保存するファイル名（例: `my-article.md`）
3. **タグ**: 記事に付けるタグ（例: ai, learning, rust）

※ 2・3は「おまかせ」でもOKです。その場合は内容から判断します。
```

### 3. 記事を執筆する

確認が取れたら、以下の構成で記事を書く：

- 下書きの箇条書きを肉付けして文章化する
- 見出し（## ）を使ってセクションを分ける
- 導入文と締めの文を加える
- 文体は確認した種類に従う

### 4. ファイルに書き出す

`src/content/posts/<filename>.md` にTOMLフロントマターを付けて保存する。

```toml
+++
title = "記事タイトル"
published = YYYY-MM-DD  # 今日の日付
draft = false
tags = ["タグ1", "タグ2"]
+++
```

## 注意事項

- タイトルは下書きの内容から自然なものを考える
- ファイル名をおまかせされた場合は、英数字とハイフンで構成する（例: `ai-learning-tips.md`）
- タグをおまかせされた場合は、内容から2〜4個を判断する
- 今日の日付は `date +%Y-%m-%d` で取得する
